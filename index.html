However, it can be set to start, end, center, or stretch to achieve different effects .container { display: grid; justify-items: start; /* Aligns items to the start of each cell */ } align-items Similar to justify-items, but for the block (column) axis. It determines vertical placement within grid cells. Set its value to start, end, center, or stretch. .container { display: grid; align-items: end; /* Aligns items to the end of each cell vertically */ } justify-content This adjusts the position of the grid itself within the container along the inline axis when there is extra space outside of explicit tracks. Options include start, end, center, stretch, space-around, space-between, and space-evenly. .container { display: grid; width: 100%; justify-content: space-between; /* Distributes extra space between columns */ } align-content Operates like justify-content, but on the block axis. This property comes into play when there's more space in the grid container than required by the tracks. .container { display: grid; height: 400px; align-content: center; /* Centers the rows vertically within the container */ } justify-items Simple definition justify-items controls the horizontal position of grid items inside their individual grid cells. Think: CELL ┌──────────────────────────┐ │ │ │ [ ITEM ] │ │ │ └──────────────────────────┘ ↑ justify-items It does not move the entire grid. It moves the items inside their cells. items Controls: ITEM inside CELL content Controls: GRID inside CONTAINER Justify-content justify-content controls the horizontal position of the entire grid inside the grid container. align-content align-content controls the vertical position/distribution of the entire grid inside its container. values: start, end, center, stretch, space-around, space-between, space-evenly Using the minmax() function: The minmax() function takes two parameters: a minimum value and a maximum value. It enables grid tracks to have a range of acceptable sizes rather than a fixed size. Media features: width: The width of the viewport. height: The height of the viewport. orientation: The orientation of the viewport (portrait or landscape). portrait: The viewport is taller than it is wide. landscape: The viewport is wider than it is tall. combining media features: @media screen and (min-width: 600px) and (orientation: landscape) { /* CSS rules for screens wider than 600px in landscape orientation */ } logical operators: and: Combines multiple conditions. All conditions must be true for the CSS rules to apply. not: Negates a condition. The CSS rules will apply if the condition is false. comma (,): Used to separate multiple media queries. The CSS rules will apply if any of the specified media queries are true. Not operator is a media query modifier it negates the media query that follows it. It allows you to apply styles when a certain condition is not met. if you use the not operator, you must also specify a media type. The not operator cannot be used with the all media type.
